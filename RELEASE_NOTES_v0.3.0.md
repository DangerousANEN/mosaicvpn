# MosaicVPN v0.3.0

## Что вошло

В клиент добавлены переключение **русского и английского языков**, а также режимы **светлой, тёмной и системной темы**. Язык и тема меняются в разделе настроек и применяются ко всему корневому приложению без перезапуска.

Главный экран теперь использует Connection Dashboard с ограниченной шириной desktop-композиции, smart-группами маршрутов, локальным выбором узла и failover-подсказками. Основные подписи dashboard, навигации, выбора маршрута и статусов переведены через единый `AppStrings` слой.

## Проверки

| Проверка | Результат |
|---|---|
| `flutter analyze` | Успешно, 0 замечаний |
| Linux release build | Успешно: `flutter build linux --release` |
| Functional/widget tests | Основные тесты проходят; отдельные screenshot golden-тесты требуют отсутствующие эталонные PNG |
| Linux VPN runtime package | Не публикуется в этом релизе: отсутствуют собранные рядом `mosaicd` и `sing-box` артефакты |
| Windows/Android/iOS/macOS | Исходники и UI-контракт подготовлены, но нативная tunnel-проверка должна выполняться на соответствующих runner/device |

> Flutter UI можно собирать в текущем окружении, но полноценный VPN-клиент требует нативного daemon/tunnel backend, системных разрешений и платформенной smoke-проверки. Поэтому неподтверждённые пакеты не публикуются как готовые к эксплуатации.

## Публикация

Исходный код доступен в репозитории [DangerousANEN/mosaicvpn](https://github.com/DangerousANEN/mosaicvpn). Для запуска Linux release bundle необходимы согласованные с проектом `mosaicd` и `sing-box`; их отсутствие в архиве означает, что bundle следует рассматривать как UI/build artifact, а не как готовый VPN-дистрибутив.

## Известные ограничения

Существующие golden-тесты ссылаются на отсутствующие файлы `goldens/*.png`; это проблема тестовых данных, а не ошибка компиляции. Android, Windows, iOS и macOS нельзя рекламировать как полностью проверенные системные VPN-клиенты до сборки на их нативных окружениях и проверки подключения, kill switch, DNS, reconnect и обновления.
