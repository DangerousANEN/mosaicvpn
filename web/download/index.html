🍎 macOS

Universal binary supporting both Intel and Apple Silicon Macs.

⬇ Download for macOS

Requirements: macOS 12.0+ (Monterey)

  1. Download the DMG
  2. Open the DMG and drag MosaicVPN to Applications
  3. Launch from Applications (right-click → Open on first run)
  4. Allow system extension in System Preferences → Security

🐧 Linux

Choose your preferred package format or run from source.

AppImage
.deb
From Source
⬇ Download AppImage (x64)

Run:

chmod +x MosaicVPN-1.0.0-rc53-x86_64.AppImage
./MosaicVPN-1.0.0-rc53-x86_64.AppImage
⬇ Download .deb (x64)

Install:

sudo dpkg -i mosaicvpn_1.0.0-rc53_amd64.deb
sudo apt-get install -f  # fix dependencies if needed

Build from source:

git clone https://github.com/DangerousANEN/mosaicvpn.git
cd mosaicvpn
git checkout rc53-leak-rufix
make build  # requires Go 1.23+ and Node 20+
