# MosaicVPN v0.3.56

Релиз качества: закрыты три дефекта, найденные при сплошном аудите кодовой базы,
и приведена в порядок раздача desktop-сборок.

## Исправлено

### Кабинет больше не выглядит пустым при холодном старте
`subscriptionsProvider` был `FutureProvider.autoDispose` без межсессионного кэша:
на каждом запуске список подписок и маршрутов был пуст до ответа демона, что
читалось пользователями как «подписка пропала». Добавлена схема
stale-while-revalidate — снимок прошлой сессии сохраняется в `SharedPreferences`
и отрисовывается мгновенно на первом кадре, затем молча заменяется свежими
данными. При недоступном демоне (offline, служба ещё не поднялась) показывается
кэш вместо экрана ошибки. Повреждённый снимок самоочищается и не блокирует старт.
Подключено на Dashboard и в инвентаре маршрутов.

### В меню станции не было пункта «Отключить»
Контекстное меню сервера на Dashboard содержало только ping / копирование /
редактирование конфига. Пользователь, открывший меню ради отключения, не находил
его вовсе. Добавлен пункт **Disconnect** (виден только у активной станции)
и соответствующий обработчик с инвалидацией статуса.

### Раздача desktop-сборок отставала на две версии
Сайт и Telegram-бот ссылались на артефакты **v0.3.54** для Windows (EXE/ZIP) и
Linux (DEB/TAR.GZ), хотя CI собрал полный набор и для v0.3.55 — обновлялся только
APK. Все пять ссылок переведены на v0.3.56, включая `MosaicVPN_0.3.56_amd64.deb`
(имя без префикса `v`, из-за чего ссылка ранее не попадала под общую замену).
