| Направление | Внесённое исправление | Автоматическая проверка | Остающийся пробел |
|---|---|---|---|
| Android Routes | Строго типизированный direct Provider Manifest вместо `Future<dynamic>` пути | Flutter analysis + widget tests | Authenticated HTTP на настоящем телефоне, cached session и manifest production |
| Android Cabinet | Direct cabinet profile и безопасное отображение вместо raw 502 exception | Flutter tests | Корректность реальных balance/expiry/device данных |

| Private pool | `/v1/servers` фильтрует `mosaic-direct`; group connect атомарен | Go + Flutter tests | Проверка, что ни один legacy advanced endpoint/UI не выдаёт пул при реальном manifest |
| Route UI | Подписки и таблица «Тип / Название / Пинг / Трафик»; Mosaic показывает только группы | 4 routes widget tests | Реальное взаимодействие мышью, touch и accessibility на устройствах |
| Settings mobile layout | `_SettingTile` переключается на вертикальный layout, segmented controls получают горизонтальную прокрутку | Flutter analysis | Скриншот и ручная проверка на 360–576dp Android |

## 5. Внешний сайт и документация: отдельные проблемы

Публичная страница пока остаётся на **v0.3.9**. Это правильно до Вашего решения по v0.3.10, но сама страница содержит устаревшие элементы, которые нельзя оставлять после стабилизации клиента:

1. Инструкция по-прежнему называет вкладку «Станции» и предлагает добавлять источник именно там, хотя новый путь — «Профили и маршруты».
2. В описании встречается «Engage Tunnel», хотя основной интерфейс больше не должен использовать этот термин.
3. Страница сообщает о «карте станций», «узлах», замерах «по каждой станции» и других деталях, которые конфликтуют с требованием не раскрывать Mosaic pool пользователю.
4. На странице всё ещё присутствуют emoji, хотя ранее была поставлена задача заменить их стилизованными иконками.
5. Страница заявляет готовность нативного Android runtime v0.3.9; это не заменяет проверку исправлений v0.3.10 на устройстве.

## 7. Публикационный риск и доступные варианты

GitHub автоматически сделал release `v0.3.10` публичным, несмотря на то что Android job остановлен. Возможны три безопасных решения:

| Вариант | Действие | Когда выбирать |
|---|---|---|
| **A. Отозвать v0.3.10** | Удалить public release и его Windows/Linux assets, оставить tag/commit для доработки | Рекомендуется, если пользователи уже могут скачать v0.3.10 и это неприемлемо до e2e |
| **B. Сделать prerelease** | Пометить v0.3.10 prerelease и добавить явное предупреждение | Если нужны технические артефакты тестировщикам, но не обычным пользователям |
| **C. Оставить public, но не рекламировать** | Не менять сайт и не добавлять Android APK | Только если Вы сознательно хотите ограниченное публичное тестирование Windows/Linux |
