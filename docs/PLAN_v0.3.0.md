---

## Принципы исполнения

1. **Никакой задачи без проверки.** Каждая задача содержит шаг «проверено», где
   проверка — реальный запуск (`go test`, `dart analyze`, сборка APK, HTTP-запрос),
   а не чтение кода.
2. **Правим причину, а не симптом.** Для каждой задачи указан установленный корень
   проблемы с файлом и строкой.
3. **Не ломаем работающее.** Перед слиянием экранов и рефакторингом — тесты.

## Волна 1. Критические дефекты (блокируют использование)

### T-01. Скрыть консольное окно sing-box
**Файл:** `internal/state/singbox_backend.go:162`
**Причина:** `exec.CommandContext` без `SysProcAttr` — Windows создаёт консоль.
**Делать:** новый файл `internal/state/spawn_windows.go` с build tag `//go:build windows`,
задающий `SysProcAttr{HideWindow: true, CreationFlags: 0x08000000}`; парный
`spawn_other.go` с пустой реализацией. Применить в месте создания `cmd`.
**Проверено:** запуск на Windows — окна нет, `go test ./...` зелёный.

### T-02. Устранить потерю подписок
**Файл:** `internal/store/store.go:241-268`
**Причина:** на Windows `os.Remove(s.path)` выполняется до `os.Rename(tmp, s.path)`.
Сбой между ними оставляет систему без файла состояния.
**Делать:** писать tmp → `f.Sync()` → сохранять `.bak` → атомарная замена; при старте,
если основной файл битый, поднимать `.bak`. Тест на прерывание между шагами.
**Проверено:** `go test ./internal/store/` с тестом на сбой + 50 циклов добавления.

### T-03. Починить проекцию карты
**Файл:** `flutter/lib/shared/widgets/world_map_widget.dart:86-99`
**Причина:** SVG растягивается на `availW×availH`; при соотношении окна ≠ 2:1
проекция `projectX/projectY` считает от искажённого холста, пины съезжают.
**Делать:** обернуть в `AspectRatio(aspectRatio: 2.0)`, вычислять размер карты как
`min(availW, availH*2) × min(availH, availW/2)`, центрировать, проекцию считать от
реального размера карты.
**Проверено:** пин Москвы (55.75, 37.62) попадает в Москву на 360 / 768 / 1440 px.

### T-04. Позиция пользователя на карте
**Файл:** `flutter/lib/features/dashboard/dashboard_screen.dart`
**Причина:** пользователь рисуется по координатам первого сервера, а не по своему
реальному выходу.
**Делать:** брать координаты из GeoIP активного соединения; если не подключён — не
рисовать пин пользователя вовсе, вместо ложной точки.
**Проверено:** при подключении к немецкому узлу пин пользователя — не в Германии.
