## Находки по вёрстке, которых не было в предыдущем аудите

### V-1. Шрифты не подключены вообще — корень «некрасивости» на Android ✅ VERIFIED

```
$ grep -A12 "fonts:" flutter/pubspec.yaml   → секции fonts НЕТ
$ ls -la flutter/assets/fonts/              → каталог ПУСТОЙ
# atlas_theme.dart:54-56
static const String serifFamily = 'serif';
static const String monoFamily  = 'monospace';
static const String sansFamily  = 'sans-serif';
```

Вся типографика Atlas опирается на три **системных алиаса**. Что это значит на практике:
на Windows `serif` → Times New Roman, на Linux → DejaVu Serif, на Android → Noto Serif,
на разных прошивках Android — разное. Один и тот же экран выглядит тремя разными продуктами.
Это первая причина, почему Android-скриншот смотрится дешевле linux-скриншота, ещё до
всех проблем с раскладкой.

Без своих шрифтов «стиль Atlas» физически не воспроизводим. Это фундамент волны 1.

### V-5. Карта — один SVG-path, страны не адресуемы ✅ VERIFIED

```
$ grep -c "<path" assets/maps/world.svg        → 1
$ grep -coE 'class="[a-z]{2}"' assets/maps/world.svg → 0
$ grep -oE 'viewBox="[^"]*"' assets/maps/world.svg   → viewBox="0 0 5760 2880"
```

Вся мировая география — **одна фигура** без id и кодов стран. Следствие: нельзя подсветить
страну сервера, нельзя окрасить регион по загрузке, нельзя сделать hit-test по стране.
Максимум, что доступно — булавки поверх картинки. Любая содержательная переработка карты
требует замены геометрии.

```

```

## Стратегия: почему именно в таком порядке

Соблазн — начать с экранов, потому что боль видна на скриншотах. Это тупик: без токенов и
шрифтов каждый экран будет переверстан в свою сторону, и через месяц получим тот же разброс
из 15 размеров шрифта, только новый.

Порядок вынужденный:

1. **Волна 0 — блокеры** идёт параллельно всему, потому что диск на 88% и врущий kill switch
   не ждут вёрстки.
2. **Волна 1 — фундамент.** Шрифты + токены + брейкпоинты + guard-тесты. Пока её нет,
   волны 2–3 запускать бессмысленно.
3. **Волна 2 — карта.** Изолирована, не конфликтует с экранами, кроме дашборда.
4. **Волна 3 — экраны.** Только после 1. Дашборд — после 2.
5. **Волна 4 — платформа.** Android-туннель независим, можно вести параллельно с 1–3.
6. **Волна 5 — качество и сайт.** Закрепляет результат тестами и CI.

Зависимости:

```
Волна 0 ──────────────────────────────────── (независима, начать сразу)
Волна 1 ──┬─→ Волна 3 (экраны)
          └─→ Волна 2 (карта) ─→ T3.2 (дашборд)
Волна 4 ──────────────────────────────────── (независима)
Волна 5 ←── требует 1,2,3
Волна 6 (сайт) ───────────────────────────── (независима)
```

## Что значит «сохранить стиль Atlas»

Чтобы у субагентов не было свободы «улучшить дизайн», фиксирую канон. Всё, что не в списке —
менять нельзя.

**Палитра** (остаётся ровно как есть, `atlas_theme.dart:12-46`):
бумага `#F4EFE6`, пергамент `#EDE5D6`, чернила `#2B2620`, терракота `#B85C38`,
оливковый `#5B7A3A`, янтарный `#C47830`, ржавый `#A8442A`, стальной `#4B6B7A`.

**Тон интерфейса** — печатный атлас: серифные заголовки, моноширинные подписи-«легенды»
капслоком с разрядкой, тонкие линии-разделители, номера разделов («Раздел II · Карточка
услуги»), подписи к рисункам («Figure 1 · Distribution of egress stations worldwide»).

**Что запрещено:** material-градиенты, скругления больше 12px, тени-elevation в стиле
Material 3, синий акцент, эмодзи-иконки в интерфейсных элементах, полностью тёмная
«хакерская» тема как основная.

**Что обязательно добавить, не ломая канон:** собственные шрифты вместо системных алиасов,
шкала размеров вместо 15 значений, сетка отступов кратно 4, мобильные компоновки тех же
блоков (карточка не превращается в другое, она просто складывается в колонку).

## Правила работы с субагентами

Модель детей: `hermes config set delegation.model` (сейчас `antigravity/gemini-3.6-flash-high`).
Параллельно максимум 5.

Жёсткие правила, выученные на грабли (см. скилл `subagent-anti-simplification`):

1. **`status=completed` — не доказательство.** Проверять файловую систему сразу по возврату
   батча: `git status --short`, наличие файлов, `wc -l`. Наблюдалось 9 из 12 задач с
   «completed» и пустым диском.
2. **Не делегировать транскрипцию.** Написать один большой файл родителю быстрее. Делегировать
   стоит исследование и точечные правки по многим файлам.
3. **Каждой задаче — команда приёмки**, которую агент обязан прогнать и вставить вывод в отчёт.
4. **Anti-simplification блок на русском** — в `context`, не в `goal`.
5. **Читать `git diff` самому** перед тем как сказать пользователю «готово».
6. **Пробники не ловят** повтор цвета, чужое слово, дрожь в 1px и обрезку текста краем — эти
   классы дефектов проверять глазами на скриншоте, A/B-диффом.

Общий блок для всех UI-задач волн 1–3 лежит в `02-wave1-design-system.md`, раздел
«Общий context-блок».
